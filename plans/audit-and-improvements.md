# Аудит проекта digitalilya — план улучшений

## Текущее состояние

- Сайт на Hugo + PaperMod
- GitHub Actions настроен, но сайт возвращает 404 (нет опубликованного контента)
- Единственный пост — черновик (`draft: true`)
- Конфиг `hugo.toml` минимальный, без настроек темы

## План действий

### Шаг 1: Опубликовать контент
- [ ] Изменить `draft: true` → `draft: false` в `content/posts/my-first-post.md`
- [ ] Создать `content/_index.md` для главной страницы (если нужна)
- [ ] Переименовать пост на русский язык: заголовок и содержимое

### Шаг 2: Настроить тему PaperMod
- [ ] Добавить `homeInfoParams` в `hugo.toml` — приветствие на главной
- [ ] Настроить `menu` — пункты навигации (Главная, Архив, Поиск)
- [ ] Настроить `socialIcons` — ссылки на GitHub и другие соцсети
- [ ] Включить поддержку тегов (`taxonomies`)
- [ ] Настроить `assets` — фавикон, цветовая схема

### Шаг 3: Добавить разделы сайта
- [ ] Создать `content/archives.md` — страница архива
- [ ] Создать `content/search.md` — страница поиска
- [ ] Настроить теги в `hugo.toml`

### Шаг 4: Улучшить CI/CD
- [ ] Проверить, что `.gitignore` добавлен в Git
- [ ] Убедиться, что после пуша сайт собирается и деплоится корректно

### Шаг 5: Финальная проверка
- [ ] Запустить `hugo server -D` локально и проверить все страницы
- [ ] Сделать `git push` и проверить GitHub Pages
